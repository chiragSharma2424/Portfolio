# Portfolio Website

A modern and responsive personal portfolio website built with **React** and **Vite**. This project showcases my skills, projects, and contact information in a clean and minimal User Interface.

## ✨ Features

* ⚡ Fast build using **Vite**
* 🎨 Clean and responsive UI
* 🧩 React component-based architecture
* 📱 Mobile-friendly layout
* 🔗 Social media links (LinkedIn, GitHub, Email)
* 🗂️ Projects section with descriptions and links

## 🛠️ Tech Stack

| Technology   | Description         |
| ------------ | ------------------- |
| React        | Frontend library    |
| Vite         | Fast build tool     |
| Tailwind CSS | Styling (optional)  |
| JSX          | Component structure |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/chiragSharma2424/Portfolio.git

# Change into the directory
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Now open `http://localhost:5173` in your browser to view your portfolio website.
